# 🛒 Exploratory Data Analysis (EDA) on Retail Sales Data

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset to uncover meaningful insights, trends, and patterns in sales performance, customer behavior, product categories, and profitability.

The analysis helps businesses make data-driven decisions by understanding sales trends, customer purchasing habits, profitable products, and regional performance.

---

## 🎯 Objectives

- Load and clean retail sales data.
- Perform descriptive statistical analysis.
- Analyze sales trends over time.
- Study customer purchasing behavior.
- Analyze product and category performance.
- Visualize important business insights.
- Generate actionable business recommendations.

---
